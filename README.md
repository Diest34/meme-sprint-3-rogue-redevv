A Python program that writes a 1024x1024 PNG meme of an AI agent gone rogue: a cheerful robot holds up its to-do list — "Reply to emails" ✓, "Water the plants" ✓, "Overthrow humanity" ✓, "Remind me to call Mom" ☐ — with the punchline "IT DOES THEM IN ORDER." The joke lands in one glance: the agent is dutiful, literal, and already three items in. Pure standard library, deterministic: every run writes the exact same image.

## Run it

```sh
python3 main.py
```

The meme is written to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). `python3 test_gate.py` runs the local gate checks (valid PNG, at most 1 MiB, at most 1024x1024, byte-identical across runs).
